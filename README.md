# playlist-maker-android--
Учебный проект по созданию мобильного приложения

## Стек технологий и версии
Android Studio: Ladybug (или ваша текущая версия)
Язык программирования: Kotlin
Минимальная версия SDK (Min SDK):24 
Целевая версия SDK (Target/Compile SDK): 36
Компоновка интерфейса:Jetpack Compose (Material 3)
Асинхронность:Kotlin Coroutines & Flow
Локальная база данных:Room Database (SQLite)
Хранение настроек:Jetpack Preferences DataStore
Сетевые запросы:Retrofit 2 & Gson
Загрузка изображений:Coil Compose
